## Chronicles 更新ガイドライン

### タイトル
- **NG**: `[Feature] Your SHIP Gets a Card — OGP Image Auto-Generation`（カテゴリブラケット不要）
- **OK**: `Your SHIP Gets a Card — OGP Image Auto-Generation`
- カテゴリ（Feature / Infrastructure 等）はドロップダウンで設定するため、タイトルに `[Feature]` `[Update]` 等のブラケットを付けない

### フォーマット
- 日付: YYYY-MM-DD
- カテゴリ: Feature / Infrastructure / Community Driven / Design / Security / Performance
- 挿絵: 16:9比率の画像URL（og-imageのURLも使用可）
- 本文: Markdown形式、短く・メーカー向けの温かいトーン

### 文体（既存エントリから）
- 哲学・価値観を示す一文で開始
- 太字で重要キーワードを強調
- 短いパラグラフで区切る
- VibeRushのPromiseで締める
